Golden Gate for Windows 11
==========================

A macOS-style desktop for Windows 11 (24H2 / 25H2). Golden Gate runs as its
own program alongside Windows. It does NOT patch any Windows system file and
it injects no code into other programs, so it is safe to install and remove.

What you get
------------
- A translucent menu bar at the top: the Golden Gate logo menu (About,
  Settings, Sleep, Restart, Shut Down, Lock), the focused app's name and
  menus, a centred clock, and status items on the right (Control Center,
  clipboard, battery, volume, Wi-Fi).
- A Dock at the bottom: pinned and running apps with magnification, a
  Downloads fan, and the Recycle Bin.
- Control Center, Mission Control (all windows), a cover-flow Alt+Tab,
  Launchpad (all apps), Spotlight search, clipboard history, Caffeine, hot
  corner, and shake-to-find-the-pointer.
- The whole system switches between light and dark (by time of day, or fixed),
  with Bibata cursors, MacTahoe-style icons on the Dock, the Inter font, an
  accent colour, and Golden Gate wallpapers.
- One settings window for everything (the logo menu > Golden Gate Settings,
  or the tray icon).

Shortcuts
---------
- Mission Control:  Ctrl+Up, the top-left hot corner, or the menu
- Launchpad:        Ctrl+Space
- Spotlight:        double-tap Ctrl
- Switch apps:      Alt+Tab (cover flow)
- Clipboard:        the clipboard icon in the menu bar

Notes
-----
- The Windows taskbar is auto-hidden by default. Change this in Settings >
  Windows (Shown / Auto-hide / Hidden). Start, notifications and Quick
  Settings keep working either way.
- To put Windows back exactly as it was (cursor, colours, wallpaper, taskbar),
  open Settings > Windows > "Restore Windows look", or just uninstall: the
  uninstaller restores everything first.
- Real app menus in the menu bar appear for classic desktop apps that publish
  a menu bar. Other apps (most modern apps) get a standard File/Edit/View/
  Window menu that drives them with the usual keyboard shortcuts.
